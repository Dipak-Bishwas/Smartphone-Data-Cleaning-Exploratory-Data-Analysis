# Smartphone-Data-Cleaning-Exploratory-Data-Analysis

## Project Overview
This project focuses on cleaning, preprocessing, and analyzing a smartphone dataset to generate meaningful business insights. The workflow includes handling missing values, removing duplicate and inconsistent records, and performing Exploratory Data Analysis (EDA) to identify trends in smartphone pricing, brands, RAM, storage, battery capacity, and processor performance.

---

## Objectives
- Clean and preprocess raw smartphone data
- Improve dataset quality and consistency
- Perform Exploratory Data Analysis (EDA)
- Identify market trends and feature relationships
- Generate business insights through visualizations

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Dataset Information
- 1,000+ smartphone records
- Multiple device-related features including:
  - Brand
  - Price
  - RAM
  - Storage
  - Battery Capacity
  - Processor
  - Display Features

---

## Data Cleaning Process
The following preprocessing steps were performed:

- Removed duplicate records
- Handled missing values
- Corrected inconsistent entries
- Filtered invalid smartphone records
- Standardized column formats
- Fixed shifted and misaligned rows
- Applied regex-based transformations

---

## Exploratory Data Analysis (EDA)
Performed detailed analysis on:

- Smartphone price distribution
- Brand popularity analysis
- RAM vs Price relationship
- Storage trends across brands
- Battery capacity analysis
- Correlation between smartphone features

---

## Key Insights
- Smartphones with higher RAM and storage generally showed higher pricing trends.
- Certain brands dominated the market in terms of product count and feature offerings.
- Battery capacity showed a positive relationship with smartphone pricing.
- Mid-range smartphones represented the largest market segment in the dataset.
